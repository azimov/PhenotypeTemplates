# Create gender criteria for templates

Create gender criteria for templates

## Usage

``` r
greateDemographicCriteria(
  minAge = NULL,
  maxAge = NULL,
  male = FALSE,
  female = FALSE
)
```

## Arguments

- minAge:

  minumum age to apply at index (NULL default)

- maxAge:

  maximum age to apply at index (NULL default)

- male:

  require male gender record?

- female:

  require female gender record?
